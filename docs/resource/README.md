# 工位、工具设备与 SOP 任务页面

当前流程：录入位置 → 独立建工位 → 录入设备规格和实物并绑定工位 → 新建项目及子项目 → 仅在子项目创建 SOP 任务 → 选择或制作 SOP → 指定发布版本与工位。

## 页面入口

- 现场资源 / 位置管理：`/production_management/location`，录入、查询、编辑、停用和删除数据库位置。使用既有 resource:read / resource:manage 权限，无需新增角色。

- 现场资源 / 工位管理：保留 `/production_management/station`，工位列表、资料编辑、数据库位置下拉选择、必填工位 IP、当前绑定设备、任务查询和扫码输入测试。工位不再创建任务，任务行跳转所属子项目并定位详情。位置可远程搜索；位置与 IP 未补齐会阻止保存。旧记录显示“待补充”。设备绑定及移出在设备资料中选择／清空工位完成。
- 现场资源 / 工具与设备：保留 `/production_management/tool`，实物、规格两个页签。设备新建／编辑表单直接包含通信配置，资料与连接原子保存；列表显示通信方式、协议、IP／接入地址；设备详情也展示地址。类型可选摄像头、扫码枪、电焊枪、量具，也可输入自定义小写类型代码。
- 项目 / 子项目详情：默认打开“SOP任务”，创建任务、指定负责人和顺序、选择工位与固定标准版本、查看标准或取消任务。原“关联 SOP”继续提供标准资料查阅，不替代任务。
- SOP 制作：右侧步骤配置增加设备规格、数量、要求和环境要求，与文字标注一起保存。从任务“制作新 SOP”进入时，带项目、子项目、任务和工位上下文，可返回子项目任务；发布后需在任务配置中显式选择发布版本。

普通页面新增动作由后端 can_manage 控制，行操作统一“编辑”下拉。已完成／归档项目及已取消任务只读。新建编号失败重试保留；409 冲突保留表单供核对，不自动覆盖他人修改。

## 扫码枪与摄像头

工位详情的扫码测试支持 USB 键盘输入模式；先点击输入框，再扫码并以回车结束。相同条码在 1 秒内重复输入被抑制，切换工位清空输入。结果只用于测试，不自动启动任务、提交质检或写执行记录；普通键盘也可模拟，不能据此确认扫码枪实物来源。

设备连接按 network/usb/serial/none 展示不同字段。USB 记录接入电脑与设备标识，工位绑定单独的终端 IP（IPv4／IPv6），网络设备继续记录各自地址；两者不会互相覆盖。摄像头支持填写包含认证信息的完整RTSP地址，连接配置统一在设备资料表单中维护。

从任务进入制作时可选择所绑定工位的摄像头，连续预览、拍照并新增到当前步骤标注。RTSP完整地址配置、FFmpeg部署与实机验证方式见 [摄像头接入说明](rtsp-camera.md)。独立制作入口需要工位上下文后才能选择摄像头。

## 联调与目录

先执行尚未执行的 [资源任务 SQL](../../../SOP_MySQL/resource-module-v1/schema.sql)，再执行一次 [位置与工位 IP 升级 SQL](../../../SOP_MySQL/resource-module-v1/migrations/001_station_location_ip.sql)，之后重启后端。可选执行 [测试位置数据](../../../SOP_MySQL/resource-module-v1/test_locations.sql)，也可直接从位置管理新增，已执行的建表／升级脚本不要重跑。root 可直接测试；普通用户执行权限定义脚本后，在用户管理中分配 resource_manager、task_editor 及需要的 SOP 编辑角色，重新登录。资源与任务分别授权，任务负责人选项专用接口只返回本项目有效编辑成员。

`src/api/resource.js` 集中调用新接口。页面统一位于 `src/views/resource/location`、`station`、`tool`，每页具有 index.vue、components、js、styles；共享组件位于 `src/shared/resource/{components,js,styles}`。原访问 URL 保持不变。任务组件位于 `views/project/detail/{components,js,styles}`。制作增量组件位于 `views/sop/editor/{components,js}`。JS import 跨目录使用绝对别名；Vue 外置 script src 使用相对路径，兼容项目 vue-jest 编译。

测试覆盖扫码去重、USB 连接版本参数、失败重试保留编号、任务子项目路径、制作上下文、步骤要求编辑，以及原项目／SOP 页面回归。尚未进行实际 MySQL 或摄像头联调。接口见 [后台文档](../../../SOP_Server_of_Java/docs/resource/README.md)。


## 设备通信与自动编号

系统设备编号在新建时自动生成（TOL + 年月日小时分钟 + 随机码），只读展示，无需手工编写。保存失败重试保留编号和通信输入。厂家序列号是选填出厂信息，不是系统设备编号，没有可留空。

通信方式统一选网络、USB、串口、无需连接。网络填写设备自身 IP／主机、端口及可选路径；USB／串口填写接入电脑和设备标识；普通工具可选无需连接。新设备首次选择摄像头规格时默认网络 RTSP，首次选择扫码枪规格时默认 USB 键盘模式，用户仍可调整。设备 IP 与工位 IP 分别管理，不自动复制。

网络列表地址显示 host:port（IPv6 使用方括号），USB／串口显示电脑与设备标识；未配置与无需连接分别显示。可按设备 IP／主机搜索。资料保存与通信配置采用同一后台事务；已有独立“连接配置”操作保留，复用同一套字段。旧设备编辑先读取最新详情与设备 version，防止列表数据遗漏连接或覆盖他人修改。

已有数据库执行 migrations/003_rtsp_address.sql 增加完整RTSP地址字段；部署时配置 FFmpeg、重启后端并刷新前端。保存地址不代表连接成功，应使用“测试连接并取图”验证实际画面。


## 2026-10-17 工位任务入口

工位详情增加 SOP 任务清单与新建入口。选择项目、子项目后复用子项目任务表单，当前工位自动带入；两个入口维护同一条任务。任务必须属于一个子项目并指定一个工位，SOP 可以暂不选择，以待配置保存。后台校验所选项目的任务权限，资源管理权限不等于项目权限；工位任务清单仅展示有项目查阅权限的数据。

新增 GET /resource/station/{id}/task，返回项目、子项目、固定标准和配置缺项。创建与编辑继续使用 /project/{pid}/subproject/{sid}/task。未取消任务保存时必须指定工位；历史空工位任务保留并要求补齐，允许直接取消。数据库继续使用现有 sop_task.station_id，不修改旧数据或增加非空约束，本次不需要执行 SQL。

SOP 制作继续上传 PNG/JPEG 作为步骤底图并保存标注，不提供模拟视频或假 RTSP。任务入口带工位上下文；发布后提示返回子项目任务，显式选择发布版本。摄像头现已支持RTSP取图和连续预览，需按摄像头接入说明配置FFmpeg并进行实机联调。


### 新建绑定与备用工位

工位入口新建时立即将当前工位带入任务表单并加载硬件，保存后写入 station_id；已有任务编辑允许切换工位。切换会刷新可用硬件，保存时确认；已配置任务缺少规定规格或数量时拒绝保存，保留原关联，可由用户明确改为待配置后保存。保持原SOP版本，不自动替换、修改图片标注或移动设备。切换成功后，原工位任务列表移除该任务，新工位可查询到同一任务。

从任务制作 SOP 时，工具设备要求仅从该工位可用硬件的有效规格中选取，按规格去重；无工位上下文的通用 SOP 制作仍可选全局规格。要求随标准版本保存，不绑定具体设备 ID。备用工位需符合规格与数量要求，拍摄角度、检测区域仍需人工复核。


## 当前入口规范（替代前述工位新建／全局新建说明）

仅从项目的子项目创建任务。工位只查询并跳转项目任务；全局SOP菜单隐藏，内部标准库不提供创建。子项目的任务配置表单维护工位、标准、制作和查阅。此批只修改前端，无需后台或 SQL 变更。


## 当前三层结构

项目仅管理子项目、成员、资料及操作记录，不直接挂标准或任务；子项目管理多个SOP任务。项目和子项目的“关联SOP”页签均已移除，制作页也不再直接关联项目，标准统一通过任务选用。任务列表提供配置、制作和查看操作，不再增加独立任务详情弹窗；工位／制作页返回时只定位并高亮任务行。旧直接关联记录和兼容接口保留，不删除或自动迁移。无需后台或SQL变更。


## 当前SOP任务工作页

项目 → 子项目 → SOP任务列表 → 任务工作页。列表的任务名称、编辑和新建统一进入 views/project/task/index.vue；不再从列表直接进入标准制作。工位任务查询也直接打开该任务工作页。

路由为 /project/{pid}/subproject/{sid}/task/new 与 /project/{pid}/subproject/{sid}/task/{taskId}。新建先保存工位、负责人等配置，成功后替换为持久任务URL，继续停留当前任务。工作页包含配置、标准选择／预览、制作操作标准以及固定标准查看；未保存修改离开前确认，制作前必须先保存。只读及已取消任务不能保存或制作。

制作页“返回SOP任务”返回原任务URL，携带本次制作的SOP及版本引用；可继续制作，发布后可明确点击“选用刚发布的版本”并保存任务。标准版本页及预览保留任务上下文；不自动修改任务采用的发布版本。任务页“返回子项目任务列表”仅返回父子项目，不返回全局SOP列表。任务归属仍是项目／子项目／任务三层，页面导航不增加业务层级。复用现有接口和权限，无需后台或SQL变更。


## 当前任务内容流程（替代此前独立标准选用流程）

任务直接编写步骤、图片与视觉标注，不再独立新建／选用／更换标准。保存任务后编写内容，草稿归属持久保存，下次继续原草稿；发布任务内容一次生效。旧内容不删除，共用内容首次编辑按任务复制，其他任务不受影响。已有数据库先执行 resource-module-v1/migrations/002_task_content.sql，再重启后台和刷新前端。详见 SOP模块当前说明。
