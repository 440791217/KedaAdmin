# SOP 任务内容版本

任务列表分别显示当前生效版本和编辑草稿版本。内容页顶部使用版本选择框，明确当前打开的版本和编辑／只读状态。

列表统一使用“操作”下拉菜单，内含“打开任务”及按权限显示的取消和删除操作；任务名称也打开同一只读页面。进入内容页后，有草稿显示“编辑草稿 Vn”，没有草稿但已有生效版显示“创建修订草稿”，首次编写显示“开始编写”；编辑中显示“退出编辑”，保留未保存修改处理。

- 查看默认读取任务绑定的生效版；尚未发布且有权限时可只读预览已有草稿。
- 编辑草稿继续唯一的现有草稿；没有草稿时从任务当前生效版复制，不从较新但未启用的历史版复制。
- 下拉列表区分草稿、当前生效、历史发布和已停用版本。切换只改变查看内容，不改变任务生效版。历史内容使用对应版本的图片接口。
- 切换前调用编辑器的保存／放弃／取消处理；取消则保留原版本及本地内容。版本加载失败保留已有画面，列表可重试。
- 没有草稿时，可把当前查看的自有历史版复制为草稿，使用现有 SOP 文档版本校验。存在草稿时不覆盖，继续编辑已有草稿。
- “发布并启用”沿用现有事务：发布草稿并更新当前任务生效版；已开工执行记录继续使用原发布内容快照。

版本列表和历史内容复用现有 SOP 项目权限接口，原任务生效版仍使用任务授权预览接口。外部引用的 SOP 只显示任务已授权的绑定版本，不主动加载来源文档的全部历史。

任务列表增加 content_draft_no 返回值，需重启 Java 后端加载 Mapper；没有该字段的旧后端仍显示“有未发布草稿”。前端版本选择框从版本列表读取准确版本号。

验证覆盖：生效／草稿／历史标签、切换历史只读、未保存取消切换、复制历史不替换生效版、从生效版创建新草稿、任务草稿编号返回及执行快照保留。日志在 D:/projects/logs。

## 发布与现场开工

SOP 发布仅准备可执行的内容，不会自动开始项目或子项目。项目、子项目均为“进行中”，且任务已发布、工位及所需设备可用时，才允许扫码开工；后端在开工接口再次校验。

未开始的项目或子项目仍可编写、发布 SOP，并在现场查看已发布指导。现场显示不可开工原因和“仅预览”，产品码输入与开工按钮禁用。已完成、归档的项目或子项目不允许新开工；已有作业保留原版本快照，仍可正常确认和完成。
