# 变更记录

## 2026-10-17

- 新增工位工作台、任务搜索与发布步骤指导，复用私有图片及标注组件。
- 后端返回现场可用标志，覆盖未发布、取消、完成归档及硬件配置问题。
- 增加步骤导航、过期响应忽略和打开前重新核对任务的测试。

2026-10-17：工位任务增加 onsite_unavailable_reasons，现场页面优先展示后台具体原因；缺少 onsite_available 时明确提示后端接口版本不匹配，不再误报任务待配置。需更新并重启后台，无SQL变更。

## 2026-10-17 扫码执行

- 新增扫码开工、未结束作业恢复、顺序步骤确认和异常处理。
- 执行记录支持产品及人员、项目、工位、时间筛选，历史内容和图片按开工版本查看。
- 引入新增三表脚本，更新前先完成手动建表。

## 2026-10-17 工位任务加载兼容修复

- 适配工程现有Vue Router 3.0.2：replace返回void，移除对返回值的.catch调用，改用完成／失败回调。原实现会在工位请求开始前抛错，造成已选工位却始终0项。
- 新增带路由的首次工位恢复、任务加载和清空工位回归测试。仅前端更新，无需SQL或后台更新。

## 2026-10-17 作业指导布局

- 预览和执行统一采用步骤流程／工位图像／文字引导三栏布局，图片成为主要展示区域。
- 图像支持按步骤切换、多图选择及放大，保留原图片标注和私有授权；空图有明确提示，上传参考图标识为非实时画面。
- 步骤确认、完成、暂停等权限和顺序校验沿用现有流程，历史记录继续使用固定版本。仅前端更新。

## 2026-10-17 现场工作区紧凑化

- 指导界面合并顶部信息和紧凑扫码条，当前步骤并入图像标题，三栏改为单一工作区分隔线。
- 图片空状态改浅色，列内独立滚动，底部操作保留在工作区内；专注模式覆盖系统侧栏和标签，可按钮或Esc退出。
- 既有开工、确认顺序和历史版本逻辑沿用，仅前端更新。
