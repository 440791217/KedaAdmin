# 现场作业

侧栏“现场作业”下提供“现场工作台”和“执行记录”。页面按 views/onsite/{workbench,records}/{index.vue,components,js,styles} 组织，执行指导组件在 src/shared/execution，接口在 src/api/execution.js。

## 操作

1. 选择工位，查看任务发布状态及配置缺项；任务只按当前账号项目权限返回。
2. 查看已发布指导，输入产品码（USB键盘扫码枪加回车，或手工输入），点击扫码开工。无resource:use权限只能查看。
3. 开工后显示固定内容快照，按顺序确认步骤；可查看其他步骤，但不能跳过确认。确认成功定位下一未完成步骤。
4. 异常暂停填写原因，恢复后继续原进度；所有步骤确认后才能完成。中止也必填原因。状态变化和步骤确认持久化保存。
5. 工位有未结束作业时展示“查看／继续作业”，不能再次开工；站点选择保存在URL，刷新可重新查到当前未结束记录。离开页面只离开界面，不结束作业。
6. 执行记录按产品码、项目名称、工位名称、操作人姓名、状态及日期查询，查看当时图文、步骤确认和事件。活动记录可进入“处理作业”；原操作人按权限继续，root可填写原因中止其他人作业，不能代签。

一工位同时一笔作业；同一任务同一产品码不允许重复（含中止记录）。返工需后续设计，不删除记录绕过限制。网络开工失败保留request_key与条码供重试，步骤写入冲突需刷新核对。开工期间产品输入锁定，避免响应丢失后误认下一产品。

## 部署

在sop_dev执行 SOP_MySQL/execution-module-v1/schema.sql 全文，新建三表；执行前不重跑旧模块SQL。随后重启后端、刷新前端。root直接使用；普通操作员可先执行同目录permissions.sql，分配现场操作员角色并加入目标项目，再重新登录。实际数据库尚需用户手动验证，测试使用隔离H2。

接口详细契约与业务规则见 ../../../SOP_Server_of_Java/docs/execution/README.md。摄像头自动检测、扫码枪身份识别、返工审批及人员交接均未接入；执行结果是人工步骤确认。

## 发布即就绪

SOP任务取消“待配置／已配置”手动选择，界面以未发布／已发布／已取消表示。保存任务不再要求status，0/1兼容旧客户端但由发布引用自动计算，2仍用于显式取消。已有发布内容的旧status=0任务无需SQL即可在现场使用；现场仍校验工位、硬件及项目关闭状态，缺项显示具体原因，不要求人工切换配置状态。更新前后端并重启后台。
