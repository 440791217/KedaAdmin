# SOP 前端变更

## 2026-10-16

- 新增SOP列表、创建、图文草稿编辑、版本历史及预览，沿用ElementUI风格。
- 项目/子项目增加固定版本关联，支持切换、排序、解绑及恢复。
- 图片经Bearer授权Blob读取，补充组件和请求契约测试。
- 需配套新版后台，已有七表无需重建；普通成员关联能力需更新可选权限脚本。

## 2026-10-16 自动业务编号

新建项目/子项目/SOP由后台生成编号，旧编号保留。启用前执行公共流水表增量脚本001_business_code_sequence.sql，不重建业务表。前端不再提交code，接口文档已更新。


## 2026-10-16 切换前端编号

采用前端类型前缀＋17位时间戳＋6位随机码，表单初始化一次、失败重试沿用；后台恢复接收code并只校验保存，移除流水服务与Mapper。旧编号及业务表保留，流水表不再是依赖，不执行删表。更新请求契约与回归测试。


## 2026-10-16 编号缩短到分钟

新编号采用PRJ/SUB/SOP-12位年月日小时分钟-6位大写随机码，移除秒和毫秒。前端生成、后台校验与测试同步更新，旧编号保持可读可编辑，数据库无迁移。旧流水服务及Mapper已删除，现有编号工具和业务异常类仍在用。


## 2026-10-16 统一SOP制作与标注

正式制作界面采用annotation三栏布局，接入步骤配置、真实底图及指引/检测区域；RTSP未接入禁用占位。新增制作增量脚本与authoring原子接口，发布/复制/项目预览保留标注。前后端补充交互、回滚、隔离和权限测试，未执行实际开发库迁移。


## 2026-10-16 工位与任务衔接

- 接入子项目 SOP 任务、独立固定标准版本与引用保护；制作及预览包含步骤设备和环境要求。详见资源模块。

## 2026-10-16 页面目录统一

- 分类根目录仅放页面目录，页面内统一 index.vue、components、js、styles；跨页面复用代码移入 src/shared 对应业务目录。
- 同步路由与测试引用，沿用原访问 URL 和业务接口；详细结构见 development/page_structure.md。

## 2026-10-17 SOP列表任务入口

- 列表明确区分“新建 SOP标准”和“新建 SOP任务”。任务入口先选择工位，再选择项目／子项目，创建时带入所选工位，沿用任务硬件与权限校验。
- 复用工位任务组件，原工位详情入口不变；本次无需后台或 SQL 变更。

## 2026-10-17 标注制作合并

- 停止加载独立标注演示页面，旧地址兼容跳转 SOP 列表；所有标注操作统一在版本制作页完成。
- 任务和版本操作明确标注制作入口；保留既有图文、标注和发布能力。无需后台／SQL 变更。

## 2026-10-17 统一任务创建入口

- SOP列表只保留“新建 SOP任务”，移除独立标准创建按钮、弹窗及其状态和请求；标准创建移入任务操作，沿用同一制作页面。
- 不调整既有标准、任务及版本数据，无需后台或 SQL 变更。

## 2026-10-17 任务收敛至子项目

- 隐藏全局标准库菜单并移除全局、工位任务创建入口；子项目为唯一创建入口。
- 新增统一任务详情，汇集工位配置、标准选用／制作与图文标注预览；工位与制作页通过task_id定位任务。
- 保留标准库搜索与版本能力、备用工位切换及后台权限，无需后台或 SQL 变更。

## 2026-10-17 项目／子项目／任务层级收敛

- 移除项目和子项目独立“关联SOP”页签、制作页直接关联入口及重复任务详情弹窗。
- 项目仅维护子项目与协作资料，任务由子项目管理，配置工位并选用标准；返回时高亮任务行。
- 既有直接关联数据及后台兼容接口保留，无SQL变更。

## 2026-10-17 独立任务工作页

- 新建／编辑统一进入任务页面，列表不再直接制作标准；保存后留在任务页面，支持工位切换、标准选用和图文标注查看。
- 制作、版本与预览保留任务上下文，返回原任务；发布版本需明确选用并保存。新增离开确认、只读及归属检查。
- 新页面遵循 project/task/{index.vue,components,js,styles}，原任务固定标准组件移到此页面。无后台或SQL变更。

## 2026-10-17 任务页简化与发布选用

- 任务页按摘要、操作标准、标准内容组织，默认收起配置，次要字段折叠；支持保存并制作／选用。
- 增加发布并用于任务的原子接口，校验源发布权限、目标任务版本与硬件，失败全部回滚；制作成功返回原任务。
- 同步前后端，需重启后台，无数据库结构变更。

## 2026-10-17 移除独立标准操作

- 任务直接编写步骤、图片和标注，移除标准创建、选用、更换和二次绑定流程；发布任务内容一次生效。
- 增加持久任务内容归属，重复进入继续草稿；旧共用内容首次编辑按任务复制，保留全部旧数据。
- 增加 002_task_content.sql，部署需先执行该升级脚本，再重启后台和刷新前端。

## 2026-10-17 统一任务查看与制作

- 任务直接使用三栏界面，支持查看／编辑切换、新建后直接编辑和任务设置弹窗；发布后留在当前任务查看，处理未保存修改。
- 查看发布内容及图片使用任务授权接口；取消／归档内容在后台同步禁止修改。本次无需新SQL。
